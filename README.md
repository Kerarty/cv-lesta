# Резюме: В БОЙ! [WIP]

Интерактивное резюме-игра для отклика на вакансию **Junior Balance Game Designer** в Lesta Games.

Кандидат — танк. Секции резюме — цели на карте. Захвати все шесть, и штаб отдаст контакты.
Каждое число в игре обосновано — это и есть портфолио балансера.

**Играть:** https://kerarty.github.io/cv-lesta/ *(после деплоя)* · **Режимы:** «HR» (авто-наведение) и «Геймдизайнер» (честный)

## Баланс: ключевые числа

### Орудие
| Параметр | HR | Геймдизайнер | Обоснование |
|---|---|---|---|
| Урон | 250 | 250 | базовая единица всех расчётов |
| Перезарядка | 0.8 с | 1.2 с | «HR не любит ждать»; v0.4 |
| Авто-наведение | есть (конус ~50°) | нет | доступность: дойти до контактов должен не-геймер |
| Привод башни | 31°/с | 31°/с | тяжело, как у сорокатонника; путь итераций 120→52→31°/с |

### Цели (порядок XP = приоритет секции в резюме)
| Секция | HP | Выстрелов | TTK (HR / ГД) | XP | Дистанция |
|---|---|---|---|---|---|
| Образование | 250 | 1 | 0.3 / 0.5 с | 500 | ближняя |
| О себе | 500 | 2 | 1.1 / 1.7 с | 1000 | ближняя |
| Навыки | 500 | 2 | 1.1 / 1.7 с | 1250 | средняя |
| Проекты | 500 | 2 | 1.1 / 1.7 с | 1500 | средняя+ |
| Опыт | 500 | 2 | 1.1 / 1.7 с | 1750 | дальняя |
| **Штаб (контакты)** | 750 | 3 | 1.9 / 2.9 с | **2500** | дальняя, движется |

TTK = (выстрелов − 1) × перезарядка + время полёта снаряда (~0.5 с) до смерти цели.
Дальность: 60 м/с снаряд, цели 15–60 м — трассер виден, но не бесит.

### Математика сессии
6 целей × (переезд 6–10 с + бой ~2–3 с) + чтение карточек 60–90 с = **2–4 минуты**.
Целевой коридор задан аудиторией: HR открывает ссылку между двумя откликами.

### Почему XP растёт именно так
XP = ценность секции для нанимающего: контакты дороже опыта, опыт дороже образования.
Порядок XP диктует маршрут игрока: самые важные секции — самые дальние и жирные.
Игрок «докупает» внимание к концу сессии, когда внимание HR на исходе.

## Итерации баланса (ченджлог целиком — в ангаре игры)

- **v0.12** — дифференциал гусениц: внешняя колея быстрее, внутренняя медленнее (v = ход ± ω×полуколя).
- **v0.10** — скорость 12→8 м/с: сорок тонн не БТ-7.
- **v0.8** — выстрел строго вдоль ствола; привод башни 120→52°/с — сведение стало скиллом.
- **v0.7** — танк тяжелее: разгон в два раза дольше (фидбек «слишком лёгкий»).
- **v0.6** — инерция движения и сглаженная камера (фидбек «дёрганое управление»).
- **v0.5** — переход на 3D; мир в метрах, стат «привод башни».
- **v0.4** — перезарядка 2.0→1.2 с: «HR не любит ждать».

Каждая правка — реакция на фидбек тестера (обычно single-person QA: самого кандидата) с числом и обоснованием.

## Технологии и запуск

- **Three.js** (CDN, без сборщика) · ES-модули · низкополигональный процедурный стиль
- Модель танка — CC0 (Quaternius), остальное нарисовано кодом
- Весь контент — `src/config.js`, весь баланс — `src/balance.js`: тексты и числа меняются без правки движка

Локально: `python dev-server.py` → http://127.0.0.1:8123 (нужен любой HTTP-сервер — ES-модули не работают с file://).

## Структура

```
src/
├── config.js      # контент: тексты секций, контакты, ссылки
├── balance.js     # баланс: статы, XP, режимы, патч-ноты
├── main3d.js      # игровой цикл, ввод, UI-состояния
├── world3d.js     # арена: небо, свет, декор (seed-генерация)
├── tank3d.js      # танк: GLB-модель, инерция, привод башни
├── camera3d.js    # камера из-за спины, pointer lock
├── shooting3d.js  # баллистика, попадания, эффекты
├── targets.js     # цели-секции резюме
└── effects3d.js   # дым и пыль
```
